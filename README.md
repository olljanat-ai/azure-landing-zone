# azure-landing-zone

Azure landing zone for the AKS platform designed in [aks-design](https://github.com/olljanat-ai/aks-design),
built with the [Azure Landing Zones IaC Accelerator](https://azure.github.io/Azure-Landing-Zones/accelerator/)
(Terraform, Azure Verified Modules). It implements **phase 1 (Foundation)** of the
[implementation project](https://github.com/olljanat-ai/aks-design/blob/main/docs/17-implementation-project-and-acceptance-testing.md):
the build tenant with management, hub, `sub-aks-dev`, pipelines with OIDC and Azure Policy in audit mode.

| Folder | Content |
|---|---|
| [`accelerator/config`](accelerator/config) | Accelerator inputs: `inputs.yaml` (bootstrap), `platform-landing-zone.tfvars` (platform), `lib/` (ALZ library overrides) |
| [`platform`](platform) | Platform landing zone generated by the accelerator (management groups, policies, management resources, hub) |
| [`scripts`](scripts) | Regenerate `platform/` and the policy enforcement block |
